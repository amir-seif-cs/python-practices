## Notebook Structure

Each exercise is presented as a focused Jupyter Notebook.

Depending on the exercise, a notebook may include:

* **Problem** — A concise description of the task.
* **Concepts** — The main Python concepts being practiced.
* **Solution** — The Python implementation.
* **Explanation** — A brief explanation of the approach when useful.

The structure may vary depending on the complexity of the exercise. The goal is to keep each notebook readable, focused, and practical rather than following a rigid template.
